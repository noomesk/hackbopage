# HackBo Web 🧬

Arte generativo bioinformático: patrones de Turing (Gray-Scott reaction-diffusion),
árboles fractales recursivos y campos de flujo orgánicos — todo en tiempo real con p5.js.

## Cómo correr
Solo abre `index.html` en un navegador (o usa un servidor local tipo `live-server`).

## Controles
- **↻ regenerar** — nueva semilla aleatoria
- **⧉ modo** — cambia entre los 3 sistemas generativos
- **⬇ guardar** — descarga el frame actual como PNG
- **Barra espaciadora** — regenerar
- **M** — cambiar modo

## Conceptos
- Reacción-difusión de Gray-Scott → patrones de Turing (manchas de leopardo, rayas de pez)
- Recursión fractal → auto-similitud, ramas de árboles/vasos sanguíneos
- Campos de flujo con ruido Perlin → dinámica de fluidos/crecimiento orgánico
